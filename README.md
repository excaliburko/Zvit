# Звіт Студіо

Мобільний PWA для наказів, кошторисів A4 та подорожніх листів A5.

Для події є три дати: користувач окремо вводить дату круглого столу та дату чеку, дата наказу обчислюється як попередній календарний день перед датою чеку. У кошторисі друкується дата наказу. У старих звітах без дати чеку її потрібно додати перед друком або повторним збереженням; дата чеку не вгадується з дати події.

## Запуск

Потрібен Node.js 24 або новіший. Зовнішніх залежностей немає.

```sh
npm start
npm test
```

Локально: http://localhost:4173. Хостинг задає порт через `PORT`; сервер слухає `0.0.0.0`. Перевірка стану: `/health`.

## Вхід і користувачі

Вхід перевіряється сервером. Облікові записи та сесії зберігаються в SQLite (`DATA_DIR/auth.sqlite`, локально `data/auth.sqlite`). Паролі хешуються scrypt, сесія передається в HttpOnly cookie та діє 12 годин. Вихід, зміна пароля та призупинення доступу відкликають сесії.

Для першого запуску задайте `BOOTSTRAP_ADMIN_USERNAME` і `BOOTSTRAP_ADMIN_HASH` у середовищі або локальному `.env`. Хеш генерується функцією `hashPassword` з `auth.mjs`. Початкові значення створюють одного адміністратора лише в порожній базі; зміна цих змінних не скидає існуючий пароль. Адміністратор додає представників через «Налаштування → Керувати користувачами». Кожен користувач змінює свій пароль у налаштуваннях. Відкритої реєстрації немає.

У Railway потрібен постійний том `/data` та `DATA_DIR=/data`, одна репліка. JSON-копія звітів не включає базу облікових записів. `.env` і локальна база виключені з Git та Docker-образу.

Дані звітів розділені за ID користувача у localStorage, без серверної синхронізації. Старі спільні дані доступні адміністратору для перенесення. Це розмежування інтерфейсу на спільному пристрої; localStorage не є зашифрованим сховищем. Для захищеного робочого простору потрібне з’єднання із сервером; PWA залишається встановлюваним, але не кешує приватні сторінки для офлайн-доступу.

## Railway

Підключіть цей репозиторій, гілку `main`. Railway використовує Dockerfile та railway.json. Після розгортання створіть публічний домен у Networking. Наступні push у main автоматично оновлюють сайт.

## Дані

Чернетки, налаштування й архів зберігаються в localStorage конкретного браузера. Для переходу на інший домен чи пристрій експортуйте JSON-резервну копію та імпортуйте її на новому сайті. Серверної синхронізації немає.

У розділі «Довідники» можна зберігати, редагувати й видаляти клініки та представників. Вибір клініки підставляє назву й місто, вибір представника — ПІБ у давальному відмінку для наказу або звичайний ПІБ водія для подорожнього листа. Адреса, контактна особа й телефони залишаються в довіднику. Зміни записів не переписують уже заповнені документи. Довідники входять до резервної копії; старі резервні копії підтримуються.

Оригінали PDF/Excel у src та матеріали перевірок у qa виключені з Git.
